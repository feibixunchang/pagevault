网页收藏

还没有安装浏览器扩展——安装后就能在任意网页一键整页保存。

外观

语言

界面字体

只影响软件界面（列表、按钮、状态栏等）；保存的网页内容保持原页面字体不变。

界面字体大小

整体放大或缩小软件界面（文字、按钮、列表一起缩放），阅读模式的正文同步变化。

粗体

界面文字加粗显示，阅读模式下的正文也一起加粗。

账号与同步

多端同步靠"同步目标"：可以填自己的 WebDAV 网盘，也可以填另一台装了网页收藏的机器（比如家里的 NAS）。同一份库可以挂多个目标，互相当备份。

令牌在那台机器的「本机作为同步源」里复制。填了它，本机就能把库推给那台机器、也能从它拉回来。

本机作为同步源

在别的设备上添加同步目标时，地址填本机的局域网地址（下方已列出）+ 这个令牌，就能把这里当作同步枢纽或备份。

备份

导出整库为 zip 备份；换电脑、重装系统后可以导入恢复。

安装浏览器扩展

按下面五步操作，大约 1 分钟即可完成（Chrome / Edge 通用）。

  1. 在浏览器地址栏输入 chrome://extensions 并打开
  2. 打开右上角的「开发者模式」
  3. 点击「加载已解压的扩展程序」
  4. 选择下面这个 extension 文件夹
  5. 完成！底部状态栏显示「扩展已连接」后，在任意网页点扩展图标即可保存整页
